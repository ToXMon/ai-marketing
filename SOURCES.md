# Sources

Distilled from four sources. Where a claim is the repo author's application rather than the source's, the file says so.

1. **Katy Lee, "Prompt-Led Marketing Strategies: Smarter Personas & Sharper Content"** — AI in Marketing: Strategic Prompt Workshop, NY Tech Week, June 2025 (19-page deck, author Katy Lee, Founder of Next Growth Wave). Read in full from the PDF the user supplied: the three prompt types (ICP, persona, content planning), B2B/B2C source lists, the ICP-vs-persona distinction, the Level 1 vs LEVEL UP prompts and the LEVEL UP example results, and the six best practices. The six LEVEL UP prompts in `prompts/` reproduce the deck's prompts (functional prompt text supplied by the user), lightly formatted with placeholders kept as written.
2. **Greg Isenberg with Cody Schneider, "AI Agents are too good at marketing now"** (YouTube, https://youtu.be/uJuxenfe-NU) — how to become a top 0.1% marketer with GrokBot, Claude Code, and the tools around them; the environment an agent needs (data warehouse, write access to ad platforms, API tools for images, video, leads); static ads built live for Idea Browser, Late Checkout, Cursor, and more; a UGC avatar video ad with motion graphics for about $5; a swipe warehouse of creative references and a creative-director agent that scores every ad.
3. **Nitya Narasimhan, PhD (Senior AI Advocate, Microsoft), "Continuous AI & AI Agentic Workflows: Using Natural Language Programming for Repository Automation Actions"** — AI Native Dev NYC Meetup / GitHub Universe Oct 2025 talk (13-page deck). The CI → Continuous AI shift, the eight Continuous workflows, the Foundry platform picture, agents across the SDLC, GitHub Next / Spark, and gh.io/gh-aw as the starting point.
4. **Phil Knight, *Shoe Dog* (2016 memoir)** — brand-storytelling lessons paraphrased from sampled passages of the 369-page PDF the user supplied. No passages are quoted. Page references are PDF pagination of that file and may differ from the print edition by a few pages.
