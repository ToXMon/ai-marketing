# Swipe Warehouse Entry Prompt

*Original prompt. The swipe warehouse is the standing library of ads that work — every new brief draws on it, every result goes back into it.*

```
Log this creative as a swipe warehouse entry. One entry per creative.

Creative: [DESCRIBE OR ATTACH — IMAGE, VIDEO, OR COPY]
Brand: [NAME + URL]
Where it ran: [PLATFORM + PLACEMENT + DATES]
Hook (verbatim first line / first 3 seconds): [QUOTE IT]
Angle: [PAIN / OUTCOME / PROOF / PRICE / SOCIAL PROOF / OTHER — ONE WORD + ONE LINE]
Format: [STATIC 1080 / STATIC 4:5 / UGC 9:16 / CAROUSEL / OTHER]
Audience: [ICP + PERSONA, ONE LINE EACH]
Copy: [HEADLINE + PRIMARY TEXT + CTA, VERBATIM]
Visual direction: [LAYOUT, COLOURS, IMAGERY, TEXT OVERLAY — 3 LINES]
Outcome: [SPEND, IMPRESSIONS, CTR, CPC, CONVERSIONS, ROAS/CAC IF KNOWN — OR "UNMEASURED, DO NOT TRUST"]
Why it worked (or didn't): [2 LINES — WHAT A FUTURE BRIEF SHOULD STEAL, AND WHAT TO AVOID]
Tags: [HOOK TYPE, ANGLE, FORMAT, AUDIENCE — COMMA SEPARATED]
```

Rules: tag every entry the same way or the warehouse becomes unsearchable. Never log an outcome you didn't measure — "unmeasured" is honest, a guessed ROAS is not. Long-running competitor ads (still live after months) are worth logging even without performance data: longevity is the signal — note it as "running since [date], outcome unknown."
